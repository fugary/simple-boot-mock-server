# 代码 Review 与精简优化指南 (Code Review & Optimization)

当需要对本次修改或新增的代码进行审查、精简与优化时，请遵循以下规范与步骤：

## 核心要求
1. **精简与去重**：
   - 检查本次改动中的重复逻辑、内联样式或冗余代码，将其提炼为公共函数、常量或全局 CSS 类。
   - 简化条件判断与数据转换流程，提升代码的执行效率与直观性。

2. **控制变动范围**：
   - 仔细核对 `git diff` / 修改历史，移除不必要的代码侵入和与功能无关的改动。
   - 避免过度重构现有稳定代码。

3. **代码优雅与可读性**：
   - 变量与函数命名需清晰明确、符合上下文语义。
   - 优先使用项目已有的公共组件（如 `common-icon`、`common-table` 等）与工具函数。

4. **规范与校验**：
   - 前端修改（Vue / JS 等）：**必须运行 ESLint 校验并通过后**方可继续。
   - 遵守项目提交约束：**严禁自动 commit**，修改需通过 git 暂存或保留在工作区供用户确认。
